# Guitarra Paso a Paso

Web para alumnos de guitarra que empiezan. Funciona en móvil e iPad, sin instalar nada.

Secciones:
- **Metrónomo**: de 40 a 200 pulsos por minuto, compás de 2, 3 o 4, tap tempo y opción de subir la velocidad poco a poco.
- **Acordes**: acordes básicos en nomenclatura castellana (Do, Re, Mi…) con su cifrado americano, diagrama, sonido y modo zurdo.
- **Afinador**: notas de referencia de cada cuerda y afinador con micrófono.
- **Práctica**: ejercicio de cambios de acordes en 1 minuto, con récords guardados en el dispositivo.

Todo está en un único archivo: `index.html`.

## Publicarla gratis con GitHub Pages

En el repositorio: Settings → Pages → "Deploy from a branch", elige la rama y la carpeta `/ (root)`.
El micrófono del afinador solo funciona si la web se abre por HTTPS (GitHub Pages lo usa).

En iPhone/iPad: abre el enlace en Safari → Compartir → "Añadir a pantalla de inicio".
